# 01. Commit

Rules for every commit in Orbit.

## Language

**All commit messages are written in English**: subject, body and footer, including commits made by AI agents.
Code identifiers, paths and quoted UI copy keep their original form.

## Format

[Conventional Commits](https://www.conventionalcommits.org/):

```text
<type>(<scope>): <subject>

<body>

<footer>
```

### Type

| Type | Use for |
| --- | --- |
| `feat` | A new user-facing capability |
| `fix` | A bug fix |
| `refactor` | Code change that neither adds a feature nor fixes a bug |
| `perf` | Performance improvement |
| `style` | Visual or formatting changes |
| `docs` | Documentation only |
| `test` | Adding or correcting tests |
| `build` | Build system or dependency changes |
| `ci` | CI configuration |
| `chore` | Maintenance that does not touch app behavior |
| `revert` | Reverts a previous commit |

### Subject & Body rules

- Imperative mood (`add`, `fix`, `unify`), lowercase start unless beginning with an acronym/proper noun, no trailing period, **72 chars max**.
- Leave one blank line between subject and body.
- **Never add AI tools as commit co-authors** (`Co-authored-by: Claude ...`, `Gemini ...`, etc. are rejected by `.githooks/commit-msg`).

## Hook enforcement

Install hooks once per clone:

```bash
git config core.hooksPath .githooks
```
