# 02. Branch

Orbit uses an integration branch (`develop`) and a release branch (`master`), and every work branch carries an `OBT-<number>` ticket prefix.

| Branch | Purpose |
| --- | --- |
| `master` | Released code only. Moves when a release or hotfix is merged. Tagged `vX.Y.Z` |
| `develop` | Default and integration branch. All work branches start here and merge back |
| `OBT-NNN/<type>-<description>` | Feature, fix, refactor, docs or chore work, cut from `develop` |
| `release/<version>` | Release preparation, cut from `develop`, merged into `master` and synced back to `develop` |
| `hotfix/<version>` | Urgent production fix, cut from `master`, merged into `master` and `develop` |

Direct pushes to `develop` and `master` are blocked by `.githooks/pre-push`; work arrives by pull request.

## Work branch name

```text
OBT-<number>/<type>-<description>
```

- **`OBT-<number>`**: three or more digits, zero-padded (`OBT-001`, `OBT-042`).
- **`<type>`**: one of `feat`, `fix`, `refactor`, `perf`, `docs`, `test`, `build`, `ci`, `chore`, `core`, `style`, `revert`.
- **`<description>`**: lowercase kebab-case.

Examples:

```text
OBT-001/feat-unify-pulsar-saturn-platform
OBT-002/fix-attachment-carryover
OBT-003/core-argon2id-login
OBT-004/docs-deploy-guide
```

## Create a work branch

```bash
scripts/new-branch.sh feat-bridge-filter       # picks next OBT number from origin/develop
scripts/new-branch.sh OBT-005/fix-sso-cookie   # or explicit branch name
```

## Enforcement

`pre-commit` and `pre-push` (`scripts/check-branch.sh`) reject invalid branch names and block direct pushes to `develop` / `master`. The `Lint PR` GitHub Actions workflow checks the head branch on every PR.
