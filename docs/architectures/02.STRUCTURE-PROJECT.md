# 02. Project Structure

```text
orbit/
├── Cargo.toml                         # Cargo workspace (orbit + pulsar + saturn libraries)
├── Cargo.lock                         # Locked Rust dependency graph
├── docker/
│   ├── axum/Dockerfile                # Multi-stage Bun + Rust release image (`circleit` uid 1001)
│   ├── nginx/
│   │   ├── Dockerfile                 # Non-root nginx:1.30.7-alpine reverse proxy
│   │   └── nginx.conf                 # Proxies / + /cable + /live/ WebSockets to axum:3000
│   └── postgres/
│       └── init-dbs.sql               # Creates orbit_pulsar (+ vector ext) & orbit_saturn
├── docker-compose.yaml                # Full postgres + axum + nginx stack (`:3000 -> :80`)
├── crates/
│   ├── orbit/                         # Unified binary, CLI (`migrate`, `seed`), bridge & SSO modules
│   │   └── src/
│   │       ├── main.rs                # Router composition, dual /health & /ready, CLI entrypoint
│   │       ├── bridge.rs              # Config, meta, issue push, attachment carry-over, status sync
│   │       └── auth_bridge.rs         # Bidirectional 1x SSO (`/sync_saturn`, `/exchange_saturn`, `/sign_out`)
│   ├── pulsar/                        # Pulsar CS Desk Rust library + Chatwoot migrations
│   └── saturn/                        # Saturn Project & Backlog Rust library + Plane migrations
├── web/
│   ├── pulsar/                        # Pulsar React Router SPA (`/app/`, includes OrbitBugModal & Orbit settings)
│   └── saturn/{web,admin,space}/      # Prebuilt Saturn React Router SPAs (`/`, `/god-mode`, `/spaces`)
├── scripts/
│   ├── build-web.sh                   # Build Pulsar SPA
│   ├── new-branch.sh                  # Cut OBT-NNN/<type>-<desc> branch from origin/develop
│   ├── check-branch.sh                # Branch name validator
│   └── check-commit-msg.sh            # Conventional Commit validator
├── tools/
│   ├── smoke.sh                       # End-to-end API, SSO, Argon2id, attachment, status-sync test
│   ├── e2e-screenshots.sh             # Ephemeral dual-DB wrapper for Playwright verification
│   └── capture-screenshots.mjs        # Headless Chromium flow + zero-error gate + 5 screenshots
└── docs/
    ├── ARCHITECTURE.md
    ├── architectures/                 # 01..04 system architecture & deployment docs
    ├── github/                        # 01..03 commit, branch, and PR workflow docs
    └── screenshots/                   # Retina screenshots verified against running Orbit server
```

## Workspace layout & key scripts

- `scripts/build-web.sh` compiles `web/pulsar/` (`bun install --frozen-lockfile && bun run typecheck && bun run build`).
- `tools/smoke.sh` creates isolated temporary Postgres DBs (`orbit_pulsar_smoke_*`, `orbit_saturn_smoke_*`), verifies Argon2id password hashes in both DBs via `psql`, exercises `/health`, SPAs, CS-to-Backlog Todo & Intake creation, attachment carry-over/download, live Done -> private note sync, and bidirectional 1x SSO + sign-out.
- `tools/e2e-screenshots.sh` launches Chromium against a fresh seeded server, tests login, right-click context menu, modal submission, Orbit destination settings, and 1x SSO jump into Saturn with zero JS/network errors.
