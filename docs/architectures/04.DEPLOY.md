# 04. Deployment

## Docker Compose (recommended)

```bash
cp .env.example .env
# Edit .env and set a strong SECRET_KEY (>= 64 hex chars)
docker compose -f docker-compose.yaml up --build -d
```

Services under `docker/`:
- `postgres` (`pgvector/pgvector:pg17`): runs `docker/postgres/init-dbs.sql` to create `orbit_pulsar` (with `vector` extension) and `orbit_saturn`.
- `axum` (`docker/axum/Dockerfile`): multi-stage Bun + Rust release build running non-root (`circleit`, uid `1001`) on `:3000`.
- `nginx` (`docker/nginx/Dockerfile`, `docker/nginx/nginx.conf`): non-root Nginx 1.30.7 Alpine reverse proxy listening on `PORT` (`:3000` host -> `:80` container), forwarding WebSockets (`/cable`, `/live/`) and HTTP to `axum:3000`.

## Bare-metal / release binary

```bash
# 1. Build frontend & release binary
scripts/build-web.sh
cargo build --release   # target/release/orbit (~32.3 MiB on macOS arm64)

# 2. Initialize & seed both DBs
createdb orbit_pulsar
createdb orbit_saturn
PULSAR_DATABASE_URL=postgres://.../orbit_pulsar \
SATURN_DATABASE_URL=postgres://.../orbit_saturn \
  ./target/release/orbit seed admin@company.com 'Strong-Password-2026' MyCompany

# 3. Start unified server
PULSAR_DATABASE_URL=postgres://.../orbit_pulsar \
SATURN_DATABASE_URL=postgres://.../orbit_saturn \
FRONTEND_URL=https://orbit.company.com \
WEB_URL=https://orbit.company.com \
SECRET_KEY="$(openssl rand -hex 50)" \
BIND=0.0.0.0:3000 \
  ./target/release/orbit
```

## Reverse proxy & security notes

- Terminate TLS with Caddy, Nginx, or Traefik and forward HTTP + WebSocket (`/cable`, `/live/*`) to `:3000`.
- When `FRONTEND_URL` / `WEB_URL` starts with `https://`, Saturn session cookies are marked `Secure`.
- Back up **both** Postgres databases (`orbit_pulsar`, `orbit_saturn`) **and** both storage directories (`PULSAR_STORAGE_DIR`, `SATURN_STORAGE_DIR`) together so carried-over chat attachments and Saturn work-item files remain consistent.

## Upstream Auto-Sync (Pulsar & Saturn)

Orbit tracks the last synced commit of Pulsar and Saturn in `upstream.lock`:
- **Local:** run `./scripts/sync-upstream.sh` (runs 3-way `git merge-file` from sibling `../pulsar` & `../saturn`, re-applies Saturn SPA switcher patches, checks Orbit bug-to-backlog safety guards, and runs `build-web.sh`, `cargo test --workspace`, and `tools/smoke.sh`).
- **Selective sync:** use `--only pulsar` / `--only saturn` and `--pulsar-ref <sha>` / `--saturn-ref <sha>` to pull specific upstream feature commits without overwriting Orbit's Jade branding or email templates.
- **GitHub Actions:** `.github/workflows/sync-upstream.yml` runs every 6 hours (`schedule`), manually (`workflow_dispatch`), or immediately on `repository_dispatch` (`types: [upstream-updated]`) and opens an `OBT-NNN/chore-sync-upstream` PR after tests & smoke checks pass.

## Optional Pulsar 4.20.1 Runtime Env Vars

- `RATE_LIMIT_CONVERSATIONS_LIST` / `RATE_LIMIT_CONVERSATIONS_FILTER` (default `1000` req/min per user+account; `0` disables)
- `PULSAR_MULTI_NODE=1` (enables Postgres-backed `pulsar_rate_limits` window counters across replicas)
- `INSTAGRAM_LOGIN_METHOD` (`unified_login` enables `INSTAGRAM_CONFIGURATION_ID` OAuth flow)

To trigger instant syncs whenever you push/release in Pulsar or Saturn, add a job with a PAT (`ORBIT_DISPATCH_TOKEN`) calling:
```bash
gh api repos/aphelion31/orbit/dispatches -f event_type=upstream-updated
```
